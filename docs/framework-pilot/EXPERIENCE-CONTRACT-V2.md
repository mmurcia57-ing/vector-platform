# VECTOR — Experience Contract V2

## Gate status
**EXPECTATION ALIGNED — WITH REFINEMENT**

This contract freezes the validated North-Star grammar before implementation. It does not freeze pixel geometry.

## Primary experience
`ORIENT → INVESTIGATE → DECIDE → COMMIT/ACT → VERIFY`

One persistent workspace carries:
- selected area/service/entity;
- analysis scenario/time scope;
- topology focus;
- evidence quality/provenance;
- investigation finding;
- commitment/action;
- outcome verification.

Navigation may change task mode, but must not reset material context without an explicit user action.

## Structural contract

### 1. Operational Universe — primary surface
The central browser area is a bounded spatial operational field, not a KPI/card grid.

Must:
- render services/entities supported by current data;
- represent supported relationships as typed edges where graph evidence exists;
- distinguish attention/stable/unknown/partial state without color alone;
- support focus/select and bounded expansion;
- preserve correlation ≠ causality;
- provide accessible relationship representation.

May:
- use synthetic/demo positioning or animation when clearly bounded.

Must not:
- imply real-time topology when unsupported;
- manufacture edges from visual proximity;
- merge entity identities silently.

### 2. Temporal Intelligence — coordinated surface
A persistent evidence spine coordinates relevant signals/incidents/changes/actions/outcomes with the selected context.

Must preserve ordering/provenance when available and represent insufficient temporal evidence explicitly.

### 3. Intelligence Inspector
Progressively discloses:
1. observed/source-backed facts;
2. deterministic derived findings;
3. hypothesis/correlation where applicable;
4. limitations/unknowns;
5. governed decision/action;
6. verified outcome.

Source evidence remains immutable; product-derived copy is localized by presentation semantics.

### 4. Decision continuity
Finding → decision → commitment → action → outcome verification remains traceable to originating service/risk/evidence context.

Execution completion is not outcome verification.

### 5. Context and scenario
Scenario/time/evidence-quality context remains visible. Demo data is explicitly non-production.

### 6. Localization
The active UI locale controls all product-generated presentation copy, accessibility labels, state labels and interaction chrome. Backend/internal identifiers may remain English. Source evidence is not silently translated.

## Material-difference invariants
Implementation fails this contract if:
- the first meaningful view becomes a KPI/card dashboard;
- topology is reduced to a secondary/decorative widget;
- investigation requires context-destroying navigation between unrelated pages;
- temporal evidence is detached from selected spatial context;
- evidence/derived/hypothesis/decision semantics collapse into one narrative;
- the visual field returns to the rejected dashboard grammar despite component-level similarity to this contract.

## Assurance scenarios
Minimum L3:
- persistent reliability risk;
- change-associated degradation;
- degradation predating change (anti-causality);
- shared dependency;
- stale/partial evidence;
- healthy negative control;
- action complete / outcome pending;
- verified outcome.

## Implementation boundary
Reuse valid existing BFF/domain behavior under NO-REDO. This contract authorizes restructuring the frontend experience, not invention of new corporate sources, topology truth, causal models, IAM, production telemetry or AI authority.
